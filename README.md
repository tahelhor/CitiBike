# CitiBike

Project Overview
The project involves creating a local data pipeline to process and analyze the Citi Bike System Data, a real-world dataset from the Citi Bike NYC bike-sharing system. This dataset includes detailed trip information, such as start and end times, stations, user types, and more, and is available for free download in CSV format. The project is ideal for beginners as it uses tools that can run on a personal computer, ensuring accessibility and cost-effectiveness. By completing this project, you’ll gain practical experience with data engineering fundamentals, which are highly valued in the industry, and create a portfolio piece that demonstrates your ability to handle data workflows locally.

Dataset Details
Name: Citi Bike System Data
Source: Citi Bike NYC
Description: This dataset contains trip data from the Citi Bike system in New York City, covering aspects like trip duration, start and end times, start and end stations, bike ID, user type (Subscriber or Customer), gender (if available), and birth year (if available). It’s updated monthly, with each file typically around 100-200 MB, making it manageable for local processing.
Format: CSV files, one for each month, downloadable directly from the website.
Size and Scope: You can start with a single month’s data (e.g., January 2025) and expand to multiple months for a more comprehensive analysis. The dataset is suitable for various analyses, such as understanding peak usage times, popular routes, and user behavior.
